Partner Messaging — org setup

1

Set up the org

Fill in the vendor package details, then press the button. It creates a new scratch org, installs the package and configures the org for messaging. About five minutes; progress shows on the right.

2

Configure the external system

The org is ready. Enter these four values in the external system (the flow and custom nodes that call Salesforce), then continue with step 3.

3

Enter the external system details

These go into the package configuration record in the org. Tick the first box once step 2 is done.

4

Run the connection test

Writes the configuration record, then opens the chat widget, sends a message, accepts the chat in Omni-Channel and checks that it shows in Enhanced Conversation. A couple of minutes.
